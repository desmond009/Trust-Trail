# Screenshots for the report

Save screenshots of the two consent screens here.

- **TrustTrail screen:** open http://localhost:8000/study/preview/P and http://localhost:8000/study/preview/F
  (preview pages record nothing).
- **Keycloak default screen:** start the study with an odd test code such as `P99`
  (http://localhost:8000/study), press Continue, log in as the demo student, and capture the
  "Grant Access to …" page. P99 is reserved for testing and excluded from the analysis.

Suggested names: `trusttrail_consent_P.png`, `trusttrail_consent_F.png`, `keycloak_consent_P.png`,
`keycloak_consent_F.png`.
